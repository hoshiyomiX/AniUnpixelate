# AniRestore - 动漫图像 AI 修复工具

[English Version](README_en.md) | **中文版本**

![示例演示](img/Example_1.gif)

**AniRestore (AniUnpixelate)** 是一款专为二次元动漫及 CGI 艺术图像设计的 AI 修复工具。它能够基于深度神经网络，对图像中的马赛克或像素化区域进行智能修复与填补。

> [!IMPORTANT]
> **技术本质说明**：本项目所使用的 AI 模型**并非生图式模型（非 Generative AI）**。它不是在“重新绘画”或“凭空想象”内容，而是通过深度卷积算法分析马赛克像素块中的颜色分布与构图规律，从而**还原/构造底层的颜色信息与画面原始结构**，实现像素级的视觉重建。

## 🌟 核心功能

- **AI 智能去遮挡**：利用预训练的深度卷积神经网络，对像素丢失区域进行纹理合成。
- **ONNX 离线推理**：集成 ONNX Runtime，所有 AI 计算均在设备本地完成，无需上传云端，保护隐私。
- **自定义修复区域**：支持用户手动涂抹或选择需要修复的区域，实现精准的局部修复。
- **无缝融合算法**：采用 Alpha 混合技术，确保 AI 生成的内容与原图背景自然过渡。
- **大区域原生分辨率修复**：选区上下文超过 640px 时自动切换分块（512×512 重叠瓦片、余弦加权融合）模式，按原图原生分辨率推理，避免单次推理的 512px 分辨率上限导致大选区发虚；小选区仍走单次推理路径。处理时界面显示逐块进度。
- **低内存设备友好**：模型通过缓存文件 + 文件路径加载（首次运行一次性解包，之后秒级加载），不在 Java 堆上分配模型字节数组；配合 `largeHeap`，在 256MB 堆限制的设备上不再触发加载期 OOM 崩溃。极端内存不足时降级为可读的错误提示而非闪退。

## 🚀 快速开始

1. **导入图像**：点击“导入动漫照片”按钮选择本地图片。
2. **选择区域**：在预览图上拖拽或涂抹出马赛克区域。
3. **执行修复**：点击“开始修复”，AI 将自动完成处理。
4. **保存结果**：修复完成后，结果将自动保存至手机相册。

## 🛠️ 技术栈

- **平台**：Android
- **开发语言**：Java / Kotlin
- **AI 引擎**：ONNX Runtime
- **模型架构**：big-lama（SAIC AI，Apache-2.0）ONNX 导出 (512×512 输入，image+mask 双输入，FFC 全局上下文)

## 📦 构建 APK

### 方式一：GitHub Actions（推荐，无需本地环境）

1. Fork 或推送本仓库到你的 GitHub 账号。
2. 进入仓库 **Actions** 页签，工作流 `Build APK` 会在每次 push / PR 时自动构建。
3. 构建完成后，在该次运行页面底部的 **Artifacts** 区域下载 `AniRestore-APK`（含 debug 与 unsigned release 两个 APK）。
4. 每次成功构建都会自动发布到仓库的 **Releases** 页：日常推送会刷新滚动预发布 `nightly`（每次构建整体替换，`nightly` Tag 始终指向最新提交）；推送形如 `v1.0` 的 Tag 则会创建以该 Tag 命名的正式 Release。两种方式均附上 debug 与 unsigned release 两个 APK（文件名含提交号 / 版本号）。

### 方式二：本地构建

```bash
# 1. 下载模型（Apache-2.0，big-lama ONNX 导出，208 MB）
#    与 CI 使用同一文件：https://huggingface.co/gumka/lama-onnx
#    放入 app/src/main/assets/model.onnx（该路径已被 .gitignore 排除）
# 2. 构建
./gradlew assembleDebug
# 产物位于 app/build/outputs/apk/debug/
```

> 注意：模型不在仓库中（见 `.gitignore`），CI 构建时会自动从 Hugging Face 拉取并校验 SHA256（见工作流文件）。模型为 **big-lama**（SAIC AI，Apache-2.0）的 ONNX 导出，输入 1×3×512×512（[0,1]）+ 掩码 1×1×512×512（1=修复区），输出按 255 尺度回归 [0,1]。缺少模型时 APK 仍可构建安装，但修复功能会提示模型缺失。release APK 未签名，分发前请自行签名（`apksigner`）。
